# System Verilog 

I am currently working on implementing an 8 bit ripple carry adder. Alongside this I am learning the syntax for SystemVerilog.
After this I plan on making an ALU and then working on making an 8-bit CPU in HDL. 
After verification, I am planning on uploading it to an FPGA board to run it.
Alongside this, I will be making my own operating system to run on the CPU.

**The timeline for this project is as follows:** 

-Start verification of ripple carry after midterm exams (Week commencing 9th of November)
-Finish ALU in December holidays
-Finish CPU after final exams
-Work on OS over the summer holidays
